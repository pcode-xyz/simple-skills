# WS-UCS 转测试提取规范

> 定义如何从 UCS-ws（WS 通道用例规约）系统性提取测试用例。
> **语言 / WS 中间件 / 架构风格以技术推演结论文档为准**（tech-stack-rule / directory-rule）。
> 本规范只定义提取方法论（通用）；具体工具/命名按 §〇 语言惯例取。

---

## 〇、按技术推演取惯例

| 维度 | 取值来源 |
|------|---------|
| WS 客户端/中间件 | tech-stack-rule（Go: gorilla/websocket；Node: ws / socket.io-client；Rust: tokio-tungstenite；Python: websockets） |
| 测试框架/文件命名/函数组织 | 按语言惯例（同 do-task 语言映射） |
| WS 网关目录 | directory-rule（不预设为 cmd/ws） |
| 竞态检测 | 按语言（Go -race 等） |

## 一、测试场景提取（从 UCS-ws）

- 主成功场景 → 正向测试（Happy Path）
- 扩展流程 → 分支测试
- 异常流程 → 负向测试
- 业务规则 → 规则验证测试
- 并发与异步设计 → 并发安全测试

**帧契约以 `docs/specs/ws/<模块>.yaml`（AsyncAPI）为准**，注意**方向语义与 HTTP 相反**：
- 「subscribe」 = 客户端→服务端（网关接收，如 user_message）
- 「publish」 = 服务端→客户端（网关发送，如 message/ai_stage/idea_*/error）

## 二、测试类型选择

| 业务特征 | 测试类型 |
|---------|---------|
| 握手认证 / 成员校验 / 帧校验（依赖真实 DB/Redis/队列） | 集成测试 |
| 跨进程广播转发（Redis 广播 → 订阅 → 房间） | 集成测试 |
| 多连接 / 多房间并发广播、竞态 | 集成测试 + 竞态检测 |
| 断线重连与缺口补齐（WS + HTTP 协作） | 集成测试 |
| 纯函数（参数解析 / 认证 / 路由 / 帧构造） | 单元测试 |
| 任务投递断言（入队聚合） | 集成测试（队列 inspector 轮询） |

> WS 网关无 HTTP E2E 那套（按所选框架）；直接驱动真实 WS 客户端 + 真实 DB/Redis。

## 三、测试文件规范

- 测试文件与网关源码同目录（按语言惯例；Go 为 package main 白盒测试）
- 文件命名：集成 `{source}_integration_test.go`、单元 `{source}_test.go`（按语言映射；与已有测试文件不冲突）
- 函数命名：`Test<场景>_UC_WS_<编号>_<场景>_<期望>`（如 `TestHandshake_UC_WS_001_JWTInvalid_Rejects401`，按语言惯例）
- 表驱动 + t.Run（按语言）组织多场景

## 四、测试覆盖矩阵（从 UCS-ws 提取）

| 维度 | 来源 | WS 示例 |
|------|------|---------|
| Happy Path | 主成功场景 | 创建者/参与者握手成功入房；user_message 落库 + 全员广播 |
| 握手拒绝 | 异常流程 | JWT 无效→401；参数缺失/非法→400；资源不存在→404；非成员→403 |

| 房间隔离 | 并发与异步设计 | 不同房间广播互不串扰；同房间多连接均收到 |

## 五、关键测试约定（对齐 UCS-ws 与实现）

1. **方向语义**：客户端发送的帧 = subscribe（如 user_message）；客户端读取的帧 = publish（服务端广播）
2. **握手拒绝**：断言 HTTP 状态码（401/400/404/403）；握手失败响应为统一结构
3. **连接内错误**：断言 error 帧（code/message/ref_id），ref_id 关联出错请求，连接级错误为 null
4. **帧内无内部字段**：客户端收到的帧不应含内部路由字段（已剥离）
5. **进程内 vs 跨进程广播**：本进程直发断言走房间直达；跨进程广播（经 Redis 转发）断言走"发布 → 订阅 → 转发"
6. **异步入队**：任务入队在广播之后异步发生，用轮询等待而非裸 sleep
7. **心跳测试**：注入短心跳值测试保活/超时，结束恢复
8. **时序不稳定处理**：Redis pub/sub 建连、goroutine 广播均异步，优先确定性直调 + 轮询，避免裸 time.Sleep
