# 松弛治愈 · relax-heal

适合调性：生活方式、健康/疗愈、冥想、家居、咖啡、内容平台、母婴。常配 zen / quiet-luxury / playful。

**设计说明**：像被阳光晒透的棉麻布，带着呼吸感的温柔。不是为了惊艳，而是为了包裹。

**比例**：主:辅:点缀A:点缀B = 6:3:0.6:0.4

**特点**：
- 高明度、中低纯度（"加了一勺牛奶"）：剔除荧光色与浓郁暗黑
- 色相偏自然的"半褪色"状态：灵感来自被阳光/风/岁月抚摸过的自然物
- 点睛色是低饱和暖大地色做"锚点"，稳住重心不让画面飘
- 自带"触觉联想"：色彩仿佛有温度和质感，唤起窝进沙发的身体记忆

**适合行业**：生活方式、健康/疗愈、冥想、家居、咖啡、内容平台、母婴
