# 意式经典 · italian-classic

适合调性：餐饮酒类、时尚奢侈、家居软装、旅游生活方式、香氛礼品、创意手作。常配 retro / editorial / luxury。

**设计说明**：温暖、戏剧性、毫不费力的优雅。不像北欧清冷、不像日式克制——是自然的慷慨 + 历史的厚重 + 艺术的激情 + 生活的热情。

**比例**：主:辅:点缀A:点缀B = 6:3:0.6:0.4

**特点**：
- 高饱和度暖色基调：焦土棕、陶土红、赭石黄、番茄红、落日橙（自带阳光温暖与历史沉淀）
- 标志性"经典三原色"点缀：少量高纯度黄/红/蓝做视觉焦点
- 低明度灰度调和：橄榄绿、灰蓝、勃艮第红缓冲平衡，少而精
- 大量"中间色"承载：奶油白、米白、亚麻、浅灰褐（带温暖底色的中性色）

**适合行业**：意式餐饮/披萨意面/咖啡、酒庄/橄榄油/奶酪/火腿、精致甜点巧克力、高端定制时尚、家居软装、精品酒店民宿、香氛蜡烛手工皂、节日礼盒、创意手作（黏土/编织/纸艺）
