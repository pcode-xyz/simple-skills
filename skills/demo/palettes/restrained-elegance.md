# 克制优雅 · restrained-elegance

适合调性：茶叶咖啡、香氛蜡烛、天然护肤、高端巧克力糕点、文具、小众服装、建筑设计工作室、高端酒店民宿、瑜伽冥想、美术馆。常配 quiet-luxury / minimal / zen。

**设计说明**：灰调复合色——像深秋远山、雨后石板、陈年纸张。安静 + 复杂 + 有分寸；冷静、克制、不喧哗、有质感。

**比例**：主:辅:点缀A:点缀B = 6:3:0.6:0.4

**特点**：
- 灰调：明度居中（眼睛最舒适区间）、饱和度不高、视觉后退、中性基底可与任何颜色融合
- 复合色：2-3 色混合，有层次耐看；哑光/浊感/朦胧，不透明不荧光
- 自然感强：像石头、泥土、树皮、远山、暮色

**适合行业**：传递"安静的高级感"而非"热闹的廉价感"——让人慢下来的产品、让人信任的品牌、让人舒服的空间：茶咖、香氛蜡烛、天然/有机护肤、高端巧克力糕点、文具笔记本、小众服装、建筑/室内设计工作室、高端酒店民宿、瑜伽冥想/心理健康、美术馆画廊
