# 低奢 · low-luxury

适合调性：高端消费、理财、会员、品牌精品、精品零售。常配 quiet-luxury / luxury / editorial / minimal。

**设计说明**：低饱和度 + 同色系搭配 + 天然哑光材质 + 适度留白 + 少量精准点缀。不是"没有颜色"，而是让颜色退后一步，让质感和气质走到台前。

**比例**：主:辅:点缀 = 6:3:1

**特点**：
- 低饱和度：颜色加灰/白/黑，视觉柔和不刺眼
- 中性色为主：米白、暖灰、驼色、燕麦、深棕、藏蓝
- 深色有层次：黑用炭黑/墨黑，深色里冷暖有变化
- 彩色只占 5-10% 面积做点缀（如一条丝巾、一幅挂画）
- 同色系弱对比：靠明度/冷暖变化造层次，过渡柔和
- 强调色精准克制：金属/深色/低饱和彩在关键位置引导视线
