# 高热度多巴胺 · dopamine

适合调性：潮流服饰球鞋、美妆个护、饮品轻食、文创潮玩盲盒、健身运动、亲子教育、年轻向家电、互联网/App、精品酒店民宿。常配 playful / neon / glass。

**设计说明**：高纯度高明度、强烈撞色、情绪化、社交媒体友好——一套有逻辑的情绪视觉法则。

**比例**：主:辅:点缀 = 6:3:1（60% 主色块 + 30% 辅色块 + 10% 高亮荧光点缀）

**特点**：
- 超高饱和与明度，拒绝中间态：极少灰调/浊调
- 强烈撞色与对比，拥抱冲突美：大色块挤压制造视觉张力
- 色彩自带味觉/触觉联想：甜蜜感、夏日感，生动鲜活，非高级冷感
- 强调即时情绪，反对深思熟虑：强社交媒体属性（极度上镜）
- 避免完全均等的色块导致视觉疲劳，60/30/10 比例

**适合行业**：潮流服饰球鞋（Y2K/街头）、美妆个护、饮品轻食、文创玩具盲盒、健身运动、亲子教育、年轻向家电、互联网/App/知识付费、精品酒店民宿
