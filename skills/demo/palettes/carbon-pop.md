# 碳灰撞色（高端景点配色）· carbon-pop

适合调性：金融科技、高端制造、健康科技、设计创意机构、先锋时尚、精品消费文化。常配 data / neon / luxury / minimal。

**设计说明**：碳灰 + 高饱和中明度亮色。冷峻的灰与鲜活的亮色相遇，形成静动、背景与主角的关系——极致的稳定与跃动。

**比例**：碳灰:高饱和 ≈ 7:3（70% 碳灰定基调 + 30% 亮色做焦点）；每行配色按 主:辅:点缀A:点缀B = 6:3:0.6:0.4

**特点**：
- 碳灰为无彩色基底：稳定、中性、包容，让眼睛休息、处理信息
- 高饱和彩为感官焦点：鲜艳不轻浮，视觉引导强，传播效率高
- 现代与经典融合，按亮色不同呈现四种质感：
  - 冷峻科技感：碳灰 + 荧光蓝/电子绿 → 精密仪器、数据中心、未来界面
  - 温润匠心感：碳灰 + 陶土红/芥末黄/松石绿 → 质朴有机、有故事性
  - 都市摩登感：碳灰 + 亮橘/品红/钴蓝 → 时尚品牌的犀利与大胆
  - 深空静谧感：碳灰 + 星云紫/星焰橙 → 深邃神秘、宇宙质感

**适合行业**：金融科技/企业服务、高端制造与工业科技、健康科技、设计与创意机构、先锋时尚潮流品牌、精品消费文化（高端餐饮/独立书店/文化空间）
