# AI 味黑名单（demo 页面默认红线）

> demo skill 生成规则之一，由 `demo-html.md` 指示，生成前（含 subagent）必须 Read 并遵守。
> 适用：Step 4 的三套预览与 Step 7 的定稿三页。

**这些是「默认」红线**——`styles/<slug>.md` 风格配方明确指定的视觉不受此限；配方没指定的，一律不得落入以下默认。交付前先把这条过一遍。

**布局**
- 禁「居中大标题 + 三张等宽 feature 卡」的模板首屏。三套预览构图必须不同；定稿页相邻两个 section 不得用同一布局家族（连续两段 image+text 交替即停）。
- 禁整页 `text-align:center` 泛滥。有内容/资产时用左对齐、不对称留白、分栏。
- 禁用 div 堆出来的「假产品截图」（假终端/假看板/假手机屏）。demo 页本身就是 UI，不需要再伪造一个"产品的截图"。
- 禁 hero 底部装饰性小字条（`BRAND. MOTION. SPATIAL.` 之类）。

**配色**
- 禁 AI 紫蓝渐变/霓虹辉光；强调色必须来自风格配方、配色池（`palettes/`）选中方案或明确的品牌色。
- 禁纯 `#000` / 纯 `#FFF`、以及无理由的浏览器默认蓝。用 off-black / off-white 或配方指定色。
- 一页一个强调色贯穿到底；footer 突然换强调色算错（风格配方明确要两段式配色时除外）。

**字体/排版**
- 禁每页都同一款系统无衬线 + 全大写标题泛滥。用配方指定字体；配方没指定的，避免全大写刷屏。
- 禁「每个 section 头顶一个小号 uppercase/mono eyebrow 标签」的节奏。最多每 3 个 section 一个。
- 英文文案禁破折号 `—` 作设计装饰；中文 `——` 是正常标点，不滥用即可。

**内容**
- 禁假精确数字（`92%`、`4.1×`、`1.2M 用户`）——没有真实数据就写定性文案，或用 `<!-- mock -->` 标注。
- 禁虚构完美占位（John Doe、Acme 类品牌名）。人名/品牌用具体、可信的。
- 禁「Quietly in use at」「Field notes」「我们尊重法国的那些」这类诗意/刻意低调文案，用平实功能文案。
- 禁把版本号标签（`V0.6` / `BETA` / `INVITE-ONLY`）放进 hero，除非产品本身就是发布/内测场景。

**图片**
- 占位图用 `https://picsum.photos/seed/<描述性seed>/<w>/<h>`，不用坏链、不用纯色块充数。
- 纯文字页不算「极简」，是没做完——hero 至少有一张真实感图片或风格化视觉（纹理/插画/图形）。
