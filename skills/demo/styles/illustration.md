# 手绘插画 · illustration

适合调性：教育、品牌、内容

> 设计一款适用于教育/品牌网页的手绘插画界面（使用 html 展示，无需模拟设备外壳，请勿添加时间、wifi 等状态条，尺寸由浏览器控制）。
> 该界面应呈现出温暖、亲切、原创的质感，采用柔和色底或奶油白，以及手绘主视觉的有机布局。使用柔和的 UI 元素、有机形状和温暖排版。
> 保持风格像原创插画师的封面。
> 使用：
> - 圆润无衬线（Nunito），标题可选手写感字体
> - 低饱和柔和多彩 + 奶油白底 + 深灰文字
> - 手绘主视觉（SVG 插画）、有机形状（不规则圆角/波浪边）、柔和色块、无边框或细手绘线、柔和阴影
> - 请勿几何硬边、请勿照片感、请勿系统默认图标
> - 原创、温暖、手作感
