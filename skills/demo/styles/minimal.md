# 简约现代 · minimal

适合调性：效率工具、B 端、通用

> 设计一款适用于手机/网页的效率工具界面（使用 html 展示，无需模拟设备外壳，请勿添加时间、wifi 等状态条，尺寸由浏览器控制）。
> 该界面应呈现出干净、克制、专业的工具感概念，采用极浅色背景、无渐变，以及网格对齐的模块化布局。使用简单的 UI 元素、规整的栅格和清晰的层级。
> 保持风格干净、现代、秩序、不喧哗。
> 使用：
> - 系统无衬线（SF Pro / Inter / PingFang），中等字重
> - 配色极简，单一强调色（自配色池选）
> - 1px 细边框、低模糊轻阴影、大圆角（12-16px）、大间距
> - 单色线性图标
> - 请勿使用彩色渐变、浓重投影或装饰性元素
> - 作品集品质的对齐与留白
