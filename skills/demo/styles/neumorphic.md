# 新拟态 · neumorphic

适合调性：工具、健康/冥想

> 设计一款适用于健康/冥想 App 的新拟态界面（使用 html 展示，无需模拟设备外壳，请勿添加时间、wifi 等状态条，尺寸由浏览器控制）。
> 该界面应呈现出柔和、静谧、专注的质感，采用同色系柔和底色，以及从背景中「鼓起来」的浮雕组件。使用简单的 UI 元素、软胶感层次和安静排版。
> 保持风格静谧、柔和、无攻击性。
> 使用：
> - 无衬线（SF Pro / Inter），中轻字重
> - 同色系浅底色，深浅两档同类色做光影
> - 外阴影（暗）+ 内阴影（亮）塑造凸起、柔和低对比、适中圆角、无边框无渐变
> - 请勿实边框、请勿高对比色、请勿锐利阴影
> - 像软硅胶从背景中浮起的静谧感
