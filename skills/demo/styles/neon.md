# 霓虹赛博 · neon

适合调性：游戏、潮流、Web3

> 设计一款适用于游戏/Web3 网页的霓虹赛博界面（使用 html 展示，无需模拟设备外壳，请勿添加时间、wifi 等状态条，尺寸由浏览器控制）。
> 该界面应呈现出炫酷、未来、有能量的质感，采用深色底，以及高饱和霓虹发光元素。使用硬朗的 UI 元素、发光边框和科技感排版。
> 保持风格炫酷、克制发光、不廉价。
> 使用：
> - 硬朗科技感无衬线，标题可粗可加字距拉伸
> - 近黑底 #0A0A0F + 霓虹青 #00E5FF / 粉 #FF2E97 / 紫 #7B5CFF + 白文字
> - 霓虹光晕 `box-shadow`、发光文字、深色玻璃面板、网格/扫描线背景、小圆角或直角
> - 请勿白底、请勿柔和低饱和、请勿衬线
> - 精确克制的发光，能量感不廉价
