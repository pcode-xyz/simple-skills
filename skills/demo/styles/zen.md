# 和风禅意 · zen

适合调性：文化、生活、手工

> 设计一款适用于文化/生活方式网页的和风禅意界面（使用 html 展示，无需模拟设备外壳，请勿添加时间、wifi 等状态条，尺寸由浏览器控制）。
> 该界面应呈现出平静、空、有留白的质感，采用暖木色调，以及极大留白的极简布局。使用极简的 UI 元素、细线分隔和安静排版。
> 保持风格像日式平面设计，一物一景。
> 使用：
> - 细字重无衬线（PingFang SC Light / 思源黑体 Light），标题可选书法感
> - 极大留白、1px 细线、自然纹理（纸感/木纹）、小圆角温和、几乎无阴影
> - 请勿高饱和、请勿大圆角胶囊、请勿浓阴影、请勿装饰元素
> - 空寂感，平静而有物
