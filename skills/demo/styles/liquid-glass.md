# 液态玻璃 · liquid-glass

适合调性：高端科技、AI、旗舰产品

> 设计一款适用于高端科技产品网页的液态玻璃界面（使用 html 展示，无需模拟设备外壳，请勿添加时间、wifi 等状态条，尺寸由浏览器控制）。
> 该界面应呈现出未来、高级、流动的质感，采用深色底（#0A0A0F）衬托折射光泽，以及分层半透明的悬浮式布局。使用简单的 UI 元素、通透的光影和轻盈排版。
> 保持风格未来、通透、像实物玻璃。
> 使用：
> - 系统无衬线（SF Pro），细字重
> - 深底 + 半透明玻璃面板 + 白色高光 + 微彩色环境光
> - 流动边缘（曲线圆角而非正圆）、顶部内高光、水滴感高光、`backdrop-filter` 半透明分层、白色 20% 细描边
> - 请勿使用扁平纯色卡片、请勿大实心按钮、请勿加装饰性渐变条
> - 光影通透、玻璃折射感
