# 毛玻璃 · glass

适合调性：年轻向、AI、社交

> 设计一款适用于手机 App 的毛玻璃界面（使用 html 展示，无需模拟设备外壳，请勿添加时间、wifi 等状态条，尺寸由浏览器控制）。
> 该界面应呈现出年轻、通透、轻盈的概念，采用彩色柔和渐变背景（青/粉/落日色），以及半透明磨砂面板的悬浮式布局。使用简单的 UI 元素、通透的层次和轻盈的排版。
> 保持风格现代、年轻、有呼吸感。
> 使用：
> - 圆润无衬线（SF Pro / Inter）
> - 渐变底（如 #667EEA→#764BA2 或柔和的多彩）+ 半透明白面板 rgba(255,255,255,.55) + 白色文字 + 一个亮色点缀
> - `backdrop-filter: blur` 磨砂、1px 半透明描边、大圆角（16-24px）、柔和投影
> - 请勿使用实心重色面板、请勿用低透明度的灰字
> - 像真实玻璃的通透层次感
