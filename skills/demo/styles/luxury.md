# 高级感 · luxury

适合调性：金融、理财、会员

> 设计一款适用于高端金融/会员网页界面的高级感界面（使用 html 展示，无需模拟设备外壳，请勿添加时间、wifi 等状态条，尺寸由浏览器控制）。
> 该界面应呈现出奢华、克制、成熟的质感，采用深色基调（近黑/深墨绿/深藏青），以及大留白的克制排版。使用克制的 UI 元素、精致的细节和优雅的字体排版。
> 保持风格高级、安静、有分量。
> 使用：
> - 衬线标题（Didot / Playfair Display / 思源宋体）+ 无衬线正文
> - 深底 #0B0B0B + 暖金点缀 #C6A15B + 象牙白文字 #F5F0E8
> - 1px 精细描边（金/白 20% 透明）、大留白、小字号大行距、克制缓动
> - 请勿使用亮蓝或纯白卡片堆叠、请勿卡通化、请勿糊成低对比
> - 克制的贵气，每个像素都在说「贵」
