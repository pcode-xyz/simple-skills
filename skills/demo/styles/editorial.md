# 杂志质感 · editorial

适合调性：内容平台、生活方式、时尚

> 设计一款适用于内容/生活方式网页的杂志质感界面（使用 html 展示，无需模拟设备外壳，请勿添加时间、wifi 等状态条，尺寸由浏览器控制）。
> 该界面应呈现出高级、有内容感、文艺的质感，采用低饱和暖色底与细腻纸张纹理，以及大号标题的出版物版式。使用简练的 UI 元素、网格对齐和优雅排版。
> 保持风格像一本高端杂志的内页。
> 使用：
> - 大号衬线标题（Playfair Display / Didot）+ 无衬线正文
> - 漫射阴影、细腻噪点纹理、大留白、小圆角或直角、网格对齐
> - 请勿使用系统默认蓝、请勿卡片堆砌、请勿霓虹色
> - 出版物级排版，像时尚杂志内页
