# 触觉立体 · volumetric

适合调性：消费、工具、年轻品质向

> 设计一款适用于消费/工具 App 的触觉立体界面（使用 html 展示，无需模拟设备外壳，请勿添加时间、wifi 等状态条，尺寸由浏览器控制）。
> 该界面应呈现出亲和、可爱、想伸手点击的质感，采用柔和色底，以及黏土/果冻般的立体组件。使用圆润的 UI 元素、柔软的层次和可爱的排版。
> 保持风格柔软、立体、有可点按的触感。
> 使用：
> - 圆润无衬线（Nunito / 圆体），中粗字重
> - 柔和高光（左上亮）、下方柔和投影、超大圆角（胶囊形）、轻微内阴影
> - 请勿平面卡片、请勿锐利直角、请勿强对比
> - 雕塑感体积，像能按下去的软糖
