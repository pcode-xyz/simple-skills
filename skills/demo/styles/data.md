# 数据驾驶舱 · data

适合调性：B 端、监控、分析

> 设计一款适用于企业监控/分析网页的数据驾驶舱界面（使用 html 展示，无需模拟设备外壳，请勿添加时间、wifi 等状态条，尺寸由浏览器控制）。
> 该界面应呈现出专业、高效、数据可信的质感，采用深色专业底或浅灰底，以及高密度信息卡的网格布局。使用紧凑的 UI 元素、图表和等宽数字排版。
> 保持风格像真的监控台，数据密度与可读性优先。
> 使用：
> - 等宽数字（SF Mono / JetBrains Mono）+ 无衬线标签，数字右对齐
> - 深底 #0E1318 + 白/浅灰文字 + 克制语义色（青 #38BDF8 / 绿 #34D399 / 橙 #FBBF24）
> - 高密度信息卡、网格布局、迷你图表（sparkline/条形）、细边框分隔、状态色编码、紧凑行距
> - 请勿大留白、请勿装饰性插画、请勿营销式大标题
> - 信息密度与可读性，专业可信
