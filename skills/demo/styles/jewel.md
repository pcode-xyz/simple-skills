# 宝石色调 · jewel

适合调性：高端消费、会员、品牌精品

> 设计一款适用于高端消费/品牌精品网页的宝石色调界面（使用 html 展示，无需模拟设备外壳，请勿添加时间、wifi 等状态条，尺寸由浏览器控制）。
> 该界面应呈现出浓郁、复古、贵气的质感，采用深宝石色基调与浅暖面板，以及克制的精品排版。使用精致的 UI 元素、暖调点缀和优雅构图。
> 保持风格浓郁、克制、像一件精品。
> 使用：
> - 复古衬线（Bodoni / Playfair Display），标题精致
> - 克制细线描边、细腻投影、浅色卡片、暖调按钮、大留白
> - 请勿冷灰蓝、请勿扁平纯色、请勿卡通
> - 浓郁而有分寸的品牌精品感
