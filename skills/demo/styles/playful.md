# 明快多彩 · playful

适合调性：儿童、社交、消费

> 设计一款适用于儿童/社交 App 的明快多彩界面（使用 html 展示，无需模拟设备外壳，请勿添加时间、wifi 等状态条，尺寸由浏览器控制）。
> 该界面应呈现出快乐、活泼、亲切的质感，采用高饱和多色块与白色面板，以及圆润大字布局。使用大胆的 UI 元素、插画元素和活泼排版。
> 保持风格满溢快乐、像儿童插画书。
> 使用：
> - 粗体圆润无衬线（Nunito / Baloo）
> - 高饱和多彩（珊瑚 #FF6B6B、黄 #FFD93D、绿 #6BCB77、蓝 #4D96FF）+ 白色面板
> - 大圆角（20px+）、粗体大字、插画/贴纸元素、彩色块、友好而明显的投影
> - 请勿极简留白、请勿灰白高冷、请勿细字
> - 快乐、亲切、有生命力
