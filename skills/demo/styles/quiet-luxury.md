# 安静奢华 · quiet-luxury

适合调性：高端品牌、理财、B 端旗舰

> 设计一款适用于高端品牌/理财网页的安静奢华界面（使用 html 展示，无需模拟设备外壳，请勿添加时间、wifi 等状态条，尺寸由浏览器控制）。
> 该界面应呈现出安静、细腻、贵而不显的质感，采用低饱和暖中性色（米白/沙/暖灰），以及极大留白的极简布局。使用极简的 UI 元素、细线分隔和精细排版。
> 保持风格安静、克制、靠细节而非装饰撑起贵气。
> 使用：
> - 精细衬线标题（Cormorant / 思源宋体细字重）+ 无衬线正文
> - 米白 #F6F4F0、墨色 #2B2B2B、少量暖铜点缀 #A0765C
> - 1px 细线分隔、柔和动效、大留白、低对比、几乎无阴影
> - 请勿金色闪亮、请勿高饱和、请勿大字号营销标题、请勿装饰元素
> - 高级的安静感，材质与细节说话
